# Other guests in the room

A reservation is under **one main guest** (the one who pays, and whose name shows on the room tablet and TV). When other people sleep in the same room, FO can add them as **other guests**. It is **optional**: a reservation with no other guests works exactly as before.

> Adding another guest **does not change the price, the number of guests (pax), the folio or the payments**. Change the number of guests with **Edit Details** as before.

## Where to add them

- **Booking page** → **Guest** card → **Other guests in the room** → **+ Add guest**. Any time, also after check-out.
- **Check-in / out** → step **2. ID Verify** → the same section under the main guest's ID photo.

## How to add

1. Press **+ Add guest**.
2. Type the guest's name, phone or email.
   - A guest who stayed before: pick them from the list.
   - A new guest: press **+ Add "name" as a new guest** and type the name (required). Nationality, passport / ID number and phone can stay empty.
3. Press **Add to this room**.
4. Optional: **⬆ Upload ID** under that guest's name for a photo or scan of their passport / ID (photo or PDF).

To take a guest off the room, press **✕** next to their name. Their guest profile is kept.

## Where other guests show

| Where | What shows |
| --- | --- |
| **Registration Card** | One line per other guest: name, passport / ID, nationality |
| **Guest Report (police report)** | One line per person, so everyone staying is reported |
| **Guest Lists** (screen and PDF) | "+ name" under the main guest |
| **Guest profile** | The stay is in their history, marked "Other guest · booked by …". Not counted in their nights / spend |
| **Edit History** | "Other guest added / removed: name" |

The room tablet and TV still show the main guest only.

> Wrong main guest? Use **⋮ → Change Guest**, not other guests.
